How I Work
01
Frame the business question

Start from what leadership actually needs to decide — e.g. "where is attrition risk concentrated" — not from whatever data happens to be available.

02
Clean, model, validate

Python + SQL for the pipeline, XGBoost/Random Forest for prediction, cross-validated before anything touches a live workflow — 88% accuracy on 300K+ records, not a guess.

03
Make it legible for non-analysts

Power BI/Tableau dashboards and plain-English AI query layers so a stakeholder gets an answer without needing to ask me first.

04
Measure what actually moved

Every project ends with a number tied to it — 18% churn reduction, 40% capacity reclaimed — not just "dashboard shipped."

Independent projects

ChurnIQ Pro

01 / 03
HTML · JS · Chart.js · Claude API

A browser-based churn analytics platform for telecom, powered by 4 specialized AI agents (Analyst, Retention, Forecast, Segment Intelligence) surfacing live churn KPIs, revenue-at-risk, and SHAP-style feature importance across a synthetic 500-record customer dataset refreshing every 5 seconds.

Includes a natural-language "AI Intelligence Search" letting users query churn drivers in plain English via the Claude API — shipped as a zero-build static app.

  • 4 agent roles (Analyst, Retention, Forecast, Segment Intel) each run a distinct system prompt against the same live dataset via the Anthropic API.
  • Synthetic data generator seeds 500 customer records and refreshes every 5 seconds to simulate a live feed, no backend required.
  • Chart.js renders the donut, bar, trend, and SHAP feature-importance views; everything runs client-side with zero build step.

SupplyIQ Pro

02 / 03
HTML · JS · Chart.js · Claude API

A 40-SKU inventory intelligence dashboard for FMCG supply chains, on seeded synthetic data — covering AI-scored stockout risk, ABC classification, and supplier reliability scoring, with a 12-week demand forecast plus a 4-week AI projection layer.

An embedded AI Analyst chat agent generates restock plans and stockout predictions on demand, feeding a prioritized restock planner with urgency tagging across all 40 SKUs.

  • ABC classification ranks all 40 SKUs by revenue contribution to prioritize which stockouts matter most.
  • A 12-week historical demand trend feeds a 4-week AI projection layer, surfaced alongside a live stockout-risk score per SKU.
  • The AI Analyst chat agent reads the current inventory state and drafts a prioritized restock plan with urgency tags on request.
View Live Demo View on GitHub

Revenue Intelligence Command Center

03 / 03
HTML · JS · Chart.js

A single-page B2B sales dashboard built from one seeded source-of-truth data layer spanning 12 months of revenue history, with a 3-period AI forecast across Bull/Base/Bear scenarios, pipeline funnel conversion, and win/loss heatmaps by segment and industry.

A rule-based AI insight engine auto-narrates live findings and answers natural-language questions computed fresh from the active filtered dataset, plus an anomaly feed flagging deviations over 14% from target.

  • One shared data layer computes every chart and KPI, so filtering by segment or industry updates the whole dashboard consistently.
  • The 3-period forecast branches into Bull/Base/Bear scenarios rather than a single projected line.
  • An anomaly feed continuously checks actuals against target and flags any metric drifting past a 14% threshold.
